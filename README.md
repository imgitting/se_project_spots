# Spots

Spots is a social media web application where users can view and share photos.

## Description

This project was built as part of my Software Engineering studies at TripleTen.  
It includes a profile section, photo cards, and interactive buttons.

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Responsive Design)
- BEM methodology
- Git & GitHub

## Project Features

- Responsive layout
- Profile section with edit button
- Photo cards with like button
- Custom fonts (Poppins)
- Deployed with GitHub Pages
